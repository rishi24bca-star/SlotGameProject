# 🎰 Slot Machine Game

An interactive **Slot Machine Game** developed using **Unity and C#**, featuring animated reels, scrolling symbols, and engaging slot machine gameplay.

The project explores Unity game development, C# scripting, GameObject management, animation systems, and WebGL deployment, making the game accessible directly through a web browser.

## ✨ Game Features

- 🎰 **Slot Machine Gameplay:** An interactive slot machine experience.
- 🎲 **Symbol System:** Multiple symbols displayed across the reels.
- 🎞️ **Animated Reels:** Smooth scrolling and movement of slot symbols.
- 🔄 **Continuous Reel Looping:** Reels continuously cycle through symbols.
- 🧩 **GameObject Management:** Organized reel and symbol elements using Unity's hierarchy system.
- 🎨 **Visual Animations:** Animated gameplay elements for a more engaging experience.
- 🌐 **WebGL Support:** Play the game directly through a web browser.

## 🚀 Getting Started

You can download and run the project locally using Unity.

### Prerequisites

- Unity Hub
- Compatible Unity Editor version
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/rishi24bca-star/SlotGameProject.git
```

**2. Open Unity Hub**

- Launch Unity Hub.
- Select **Add Project from Disk**.
- Navigate to the cloned `SlotGameProject` folder.
- Select the project and open it using Unity.

**3. Run the game**

- Open the main game scene from the Assets folder.
- Press the Play button in Unity Editor.
- Enjoy the slot machine gameplay!

## 🌐 WebGL Deployment
